# Sales Data Analysis using Python & Pandas

## Overview

This repository contains a sales data analysis project built using Python and Pandas. The project focuses on cleaning raw sales data, performing revenue calculations, filtering and grouping data, and generating meaningful business insights through analysis and visualizations.

## Features

* Data cleaning and preprocessing
* Revenue calculation using Quantity and Price
* Grouping and aggregation using Pandas
* Filtering data based on conditions
* Trend analysis and visualizations
* Product-wise sales and revenue analysis

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Project Workflow

1. Imported and explored the dataset
2. Cleaned missing and inconsistent values
3. Converted data types for analysis
4. Calculated revenue and sales metrics
5. Performed grouping and aggregation
6. Created visualizations for trends and insights

## Sample Analysis Performed

* Product-wise revenue analysis
* Quantity and revenue trends over time
* Average revenue and quantity calculations
* Monthly sales filtering and comparison

## Conclusion

This project demonstrates practical data analytics skills using Python and Pandas. It highlights how raw business data can be transformed into actionable insights through cleaning, analysis, and visualization techniques.
